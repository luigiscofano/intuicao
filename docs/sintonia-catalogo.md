# SINTONIA — catálogo editorial das 500 fases

Este índice corresponde a 500 definições completas em `dist/sintonia/campaign.mjs`. Busque o ID no arquivo para consultar mapas, posições, caixas, conexões, estados iniciais, versão, semente, solução, descoberta, conceitos secundários e diagnóstico de repetição. O arquivo é formatado para leitura humana.

Todas as sequências abaixo foram reproduzidas com vitória no mesmo motor usado pelo jogo. A busca em largura garante a distância mínima desses certificados. Essa distância é informativa: o jogo não exige otimização. Os mapas foram construídos por estruturas parametrizadas e curadoria automática; não há declaração de testes com jogadores.

Setas: ↑ cima · → direita · ↓ baixo · ← esquerda. Todas as setas valem para todos os animais.
