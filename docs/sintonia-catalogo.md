# SINTONIA — catálogo editorial das 500 fases

Revisão de conteúdo **`sintonia-content-2`** · gerador **2** · regras **1**. Este índice é gerado das definições completas de `dist/sintonia/campaign.mjs`, sem copiar números de uma revisão anterior.

76 mapas foram mantidos (1–75, 176); 424 foram reconstruídos. A coluna “Padrão” identifica a composição declarada; “não tipificado” não inventa uma classificação para as demais geometrias. Famílias e padrões são classificações editoriais, não provas de descobertas distintas.

Todas as 500 soluções foram validadas e reproduzidas com vitória no motor do jogo. 500 certificados registram optimalidade; somente esses recebem “mínimo”. Os demais seriam apresentados como testemunhos, nunca como mínimos. Comprimento não mede dificuldade humana. **Não há testes humanos concluídos nem aprovação automática pela rubrica editorial.**

As fichas integrais registram descoberta, dicas, justificativa de manutenção/reconstrução, papéis e testemunho de eventos. Necessidade e limites das consultas ficam separados em `tests/sintonia-purpose-audit.json` e [evidências de propósito](sintonia-purpose-evidence.md). Uma utilização no certificado não basta para chamar um elemento de indispensável.

Setas: ↑ cima · → direita · ↓ baixo · ← esquerda. Cada seta vale para todos os animais.
