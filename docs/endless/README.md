# Modo sem parar

[Funcionamento dos geradores](GERACAO-PROCEDURAL.md) · [Reconciliação de publicação](../qualidade/reconciliacao-runtime-2026-11.md)

As campanhas e seus identificadores permanecem independentes dos desafios procedurais. A dificuldade escolhida orienta os próximos desafios; reiniciar preserva o desafio atual, e gerar outro não registra vitória.
